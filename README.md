# Harmonic-template evidence and symbolic note transcription

Python 3.11 CPU, NumPy. Run `python demo.py` for real ordinary single-note
spectral explanation and threshold/merge transcription. Inputs are synthetic
short-time nonnegative spectra, with supplied calibrated templates and grid.
No waveform extraction, audio dataset, listening quality or pretrained model is
required. The starter does not perform joint multi-template decomposition,
temporal regularization, onset-aware segmentation or valid multi-voice search.
